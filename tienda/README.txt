RREADME – Perfume Shop (PRA1 – Comercio Electrónico)

1. Descripción general del proyecto

    Este proyecto desarrolla una tienda online básica de perfumes como parte de la Práctica 1 (PRA1) de la asignatura Comercio Electrónico de la UOC.
    Incluye:

        · Frontend de la tienda: navegación por categorías, productos, carrito y proceso de compra.

        · Procesamiento de pedidos: compra como invitado y como usuario registrado.

        · Panel de administración: consulta de pedidos y detalle de cada compra.

        · Persistencia de datos mediante MySQL/MariaDB.

    La aplicación ha sido diseñada para funcionar en cualquier entorno estándar de XAMPP sin necesidad de modificar archivos de Apache ni rutas absolutas.

2. Requisitos del sistema

	· XAMPP o equivalente con:

		· PHP ≥ 8.0

		· MariaDB/MySQL

		· Apache ≥ 2.4

	· phpMyAdmin para importar la base de datos

	· Navegador web actualizado

3. Instalación del proyecto

	3.1. Copiar el proyecto a htdocs

		Descomprimir la carpeta del proyecto dentro de:
			C:\Xampp\htdocs\
